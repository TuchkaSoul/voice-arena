Как звучат два канала

Четыре фразы, два голоса. Сравните исходный WAV и две версии Opus на одних наушниках и при одинаковой громкости.

Для этих записей увеличено время самой генерации. Последние слова проверены распознавателем до добавления паузы. После речи оставлено ещё 0,45 секунды. Кнопка «Послушать конец» запускает последние 3 секунды файла — проверьте, целиком ли звучит последнее слово.
О проверке и сохранении оценок

Оценки и заметки хранятся в этом браузере. Скачайте JSON, чтобы сохранить их отдельно. Названия каналов можно скрыть для сравнения без подсказки; порядок записей при этом не меняется. Это открытое прослушивание, без формального расчёта MOS.

Обе версии Opus: 24 кбит/с, режим voip. Отличаются подготовка сигнала и его частота на входе кодека. Целевая громкость всех файлов −23 LUFS. Последние слова распознаны автоматически, но это не гарантирует правильность всех звуков — окончательную оценку дайте на слух.

Для совместимости плееры Opus воспроизводят WAV-копии, декодированные из готовых Ogg без фильтров. Оригинальные Ogg доступны рядом с каждым плеером.

Это новая генерация с запасом времени. Результаты анализатора из прежних серий к этим файлам не относятся.
